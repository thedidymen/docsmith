# Academic Thesis Template

Generic thesis-style template for Docsmith example documents.

Included assets:
- `template.tex`
- `defaults.yaml`
- `metadata.yaml`
- `partials/titlepage.tex`
- `partials/before-body.tex`
- `partials/after-body.tex`
- `partials/appendix.tex`

Current behavior:
- title page from document metadata
- table of contents
- A4 layout with 2.5cm margins
- numbered sections
- Pandoc citeproc support when bibliography / CSL are configured
- appendix support via the `<!-- APPENDIX -->` marker in source Markdown
