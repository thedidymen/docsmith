# Citations

Docsmith can pass bibliography and CSL configuration through to Pandoc. In this guide,
the citation files live next to the document spec:

- `references.bib`
- `csl/apa.csl`

Inline citations work in normal authoring text, for example [@wilson2021] and
[@pandoc2025].

The practical value is not just citation formatting. It also keeps source material
declarative and reproducible, which aligns with the document-engine goal described in
the overview [@wilson2021].
